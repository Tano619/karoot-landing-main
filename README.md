# Karoot Landing Website

This is a simple informational landing website for `karoot.ca`.

Karoot is a coming-soon mobile app that helps pet owners find pet grooming and pet care services across Canada, including services for dogs, cats, rabbits, and other pets.

## Quick Start

1. Install Node.js from <https://nodejs.org>.
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open <http://localhost:3000> in your browser.

## Edit Website Text

Most website text is in:

```text
src/config/site.ts
```

Open that file to change:

- App name
- Tagline
- Button labels
- Store links
- Features
- FAQ answers
- Contact email

## Useful Commands

```bash
npm run dev
```

Starts the local website while you edit it.

```bash
npm run build
```

Checks that the website is ready to deploy.

## Deploy

The site is built with Next.js and can be deployed to Vercel with the default Next.js settings.
